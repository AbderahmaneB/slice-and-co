# Original Slice & Co typefaces

These unmodified Google Fonts WOFF2 files preserve the four families from the original site CSS: Anton, Oswald, Pacifico and Inter. Only Latin subsets are served; their range includes French accented letters and OE ligatures (U+0152/U+0153).

| Family | Normal weights | Local file | License |
| --- | --- | --- | --- |
| Anton | 400 | anton-latin-400.woff2 | OFL-Anton.txt |
| Oswald | 400–700 | oswald-latin-400-700.woff2 | OFL-Oswald.txt |
| Pacifico | 400 | pacifico-latin-400.woff2 | OFL-Pacifico.txt |
| Inter | 400–700 | inter-latin-400-700.woff2 | OFL-Inter.txt |

Oswald and Inter use a single variable WOFF2 file each for weights 400 through 700. Google Fonts returns the same binary for each requested weight.
